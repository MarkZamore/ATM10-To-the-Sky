# ATM10 To the Sky

Подготовка сборки 2.3.1 для LANMinecraft. [Авторский клиентский выпуск](https://www.curseforge.com/minecraft/modpacks/all-the-mods-10-sky/files/9368148)

`tools/upstream-client-lock.json` фиксирует SHA256 и размер оригинального ZIP, ссылки на официальный источник, записи зависимостей и SHA256 файлов внутри авторских overrides. Minecraft и загрузчик взяты из оригинального манифеста. Java в `portable-pack.json` соответствует выбору текущего лаунчера для этой версии Minecraft и проверяется при запуске.

## Восстановление авторского клиента

Закреплённый авторский клиент CurseForge использует project ID 1298402 и file ID 9368148.
Для подготовки текущего кандидата из корня LANMinecraft запустите:

```powershell
python -B tools/PackData/CurseForge/release_overlay.py stage --pack-source LocalSources/ATM10-To-the-Sky --output $stage
```

`tools/overlay.json` сохраняет политику открытия мира через Steam. Для нового авторского выпуска снимите отдельную квитанцию через `prepare.py --client-only` и проверьте её командой `release_overlay.py review-update`. При изменении защищённого входа пересмотрите рецепт и закрепите новые точные байты. После нативной проверки сохраните полный `tools/upstream-lock.json` и выполните `release_overlay.py verify` по готовому манифесту.

Рецепт добавляет клиентский скрипт KubeJS для предупреждения в меню и `config/memorysettings.json` для раннего окна. Для сборки поставки требуется версия инструментов LANMinecraft, поддерживающая `memorySettingsConfig`, начиная с `697e3e2fc43e3b9337017d7bb7c6454492486c11`. Конфиг взят из настроек по умолчанию Memory Settings 6.0. Единственное изменённое значение `minimumClient` равно нулю, поэтому ранняя рекомендация по объёму ОЗУ пропускается и сохраняется отдельная проверка 32-битной Java. Выделение ОЗУ и рекомендация в лаунчере сохраняются. Сборка владеет этим файлом настроек Memory Settings. Если он изменён в старой установке, лаунчер сначала сохраняет прежние байты в `Minecraft/Personal/PackConflicts`.

При появлении авторского `config/memorysettings.json` или новой версии Memory Settings проверка рецепта требует пересмотра. Остальные авторские обновления сохраняют слой. Сгенерировать конфиг и проверить его загрузку через Cupboard можно командой `java --class-path <libraries> tools/GenerateMemorySettingsConfig.java <empty-probe-directory> <output-config>`. Не включайте LWJGL в библиотеки этой проверки. Так проба подтвердит, что рекомендация штатной версии и проверка разрядности доходят до вызова системного окна, и окна при этом не откроются. Скрипт меню проверяется отдельно. Если автор переместит или заменит его зависимости, проверьте API и загрузку скрипта перед обновлением закреплённых ID.

Для адресной проверки дайте Java 21 библиотеки точного NeoForge, Minecraft и модов Memory Settings, Cupboard и Rhino. В пустой рабочей папке вызовите `java --class-path <libraries> tools/MemoryWarningProbe.java <script> <memorysettings.json>` с абсолютными путями. Возьмите конфиг установленной сборки с включённым предупреждением и порогом 8500 МиБ. Тест исполняет настоящий скрипт в Rhino, сверяет изменившееся поле и сравнивает байты копии конфига. Для проверки меню запустите сборку с 12 ГиБ.
